# 3. CAPTCHA Results

**Purpose:** a focused list of the pages where a CAPTCHA was found, with its type.

## How to use
1. Open `/results`.
2. Keep "CAPTCHA Detections Only" on to hide clean pages.
3. Click **Inspect** to see the screenshot and evidence.

## What it shows
Page path and title, HTTP status, forms found, provider badge (Google reCAPTCHA / hCaptcha / Turnstile), handling strategy (`human_review`), review status.
Confidence shows "-" because per-page confidence is not measured; the tool does not invent a number.
