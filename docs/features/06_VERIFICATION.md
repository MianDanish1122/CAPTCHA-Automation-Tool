# 6. Verification

**Purpose:** send a token to the provider's official verification service using the providers' published **test** keys, and record the real answer.

## How to use
1. Open `/verification`.
2. Choose a provider and submit the test token.
3. Read the result in "Recorded attempts".

## Outcomes recorded
verified, failed, already used, missing token, provider unavailable. A success is never faked. No production keys are used.
