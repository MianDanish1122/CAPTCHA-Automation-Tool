# 8. Reports

**Purpose:** download results.

## How to use
1. Open `/reports`.
2. See past batches and counters (total batches, CAPTCHAs documented, verified clean sites).
3. **Export CSV** for the audit report; the batch screen also offers Expected-vs-Detected as CSV or Markdown.

## Safety
Cells starting with `=`, `+`, `-`, `@`, tab or CR are prefixed with `'` so spreadsheets cannot run injected formulas.
